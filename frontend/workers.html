Statistik Cloudflare

Dipakai tombol “Statistik” di kartu worker. Kredensial hanya dipakai untuk memanggil Cloudflare lewat /api/workers-stats dan tidak disimpan di browser.

Kuota hari ini (UTC)

Pemakaian request tiap Worker sejak 00:00 UTC sampai sekarang, dihitung Cloudflare lewat /api/workers-stats (mode period: "today"). Semua Worker diambil dalam satu permintaan, jadi jatah analitik tidak habis per worker. Kredensial memakai isian di panel “Statistik Cloudflare” di atas dan tidak disimpan.

Kuota plan tidak bisa dibaca dari API Cloudflare (endpoint billing menolak), jadi angka kuota di bawah adalah isian: bawaan 100.000 request/hari per Worker (plan free). Ubah kalau plan Anda berbeda — isian disimpan di browser ini.
